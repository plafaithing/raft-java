==========================================
  Raft Performance Benchmark Tool

Usage: benchmark.sh <test_type> [options]

Test Types:
  throughput   - Test throughput (requests/sec)
  election     - Test leader election convergence time
  hetero      - Test heterogeneous cluster (leader preference)
  stress       - Start node stressor (cpu/memory/network)
  all         - Run all tests

Examples:
  benchmark.sh throughput 10 60   # 10 threads, 60 seconds
  benchmark.sh election              # Test leader election (kill leader manually)
  benchmark.sh stress cpu             # Simulate high CPU load on this node
  benchmark.sh stress memory          # Simulate high memory usage on this node
  benchmark.sh hetero 10 60       # Test heterogeneous cluster
